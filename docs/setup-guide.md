# Setup Guide

This project is built using React, TypeScript, and Vite. Follow these steps to run the Predictive Port Operations Control Centre locally.

## 1. Clone the repository
\`\`\`bash
git clone https://github.com/PritTejani-1658/bob-ai-hackathon-Ai-Architect.git
cd bob-ai-hackathon-Ai-Architect
\`\`\`

## 2. Install dependencies
Ensure you have Node.js installed (v16 or higher is recommended).
\`\`\`bash
npm install
\`\`\`

## 3. Configure environment
Create a local environment file.
\`\`\`bash
cp .env.example .env
\`\`\`

## 4. Run the project
Start the Vite development server.
\`\`\`bash
npm run dev
\`\`\`

The application will be available at \`http://localhost:5173\`.
